Safety First · ก่อนเริ่มงาน

🚨 ห้ามลืมเด็ดขาด

  • ใส่ PPE ครบ (หมวก · แว่น · รองเท้าเซฟตี้ · ที่อุดหู)
  • เช็คพื้นที่ → ไม่มีคนในเขตอันตราย
  • เช็ค E-Stop ทุกจุดอยู่ในสภาพปล่อย
  • ฝาครอบ/ประตู ปิดสนิททุกตัว
  • มีปัญหา → หยุดทันที + แจ้งหัวหน้า
  • ก่อนซ่อม → LOTO (Lock-Out Tag-Out)
🎯 ใส่ PPE ครบทุกครั้งก่อนเข้าหน้างาน

🗂️ HMI Alarm → ค้น Tag → DB/UDT → ฮาร์ดแวร์จริง

PLC Tag · UDT · DB 🤔

PLC Tag = ตัวแปร เก็บที่อยู่ I20.0

UDT = รวมสัญญาณอุปกรณ์เป็นชุด (Motor = Start/Stop/Alarm/Status)

DB = กล่องเก็บข้อมูลตอน Run DB304

🔎

2 วิธีค้นหา

01
🏷️ Tag Info / Cross-ref
เปิด Variable Table → เลือกตัวแปร → Cross-reference
02
🔍 Direct Search
พิมพ์ที่อยู่ตรงๆ: I20.0 · Q50 · DB304
# ตัวอย่างค้น SEARCH "I20.0" # Input SEARCH "Q50" # Output SEARCH "A10" # Zone OPEN DB304 # Data
📋

Workflow แก้ Alarm

1
เตรียม: E-Stop ปล่อย, ฝาปิด, Warm ON, Reset
2
มี Alarm? จดรหัส เช่น A10/FLD1
3
PLC Tag → Cross-ref หรือ Search
4
เปิด UDT/DB เช่น Motor_UDT
5
Output Q ไม่ออก? → คอนแทคเตอร์/รีเลย์
6
Input ไม่เปลี่ยน? → เซ็นเซอร์/สาย/24VDC
7
Online/Monitor ดู bit เปลี่ยนจริง
8
แก้ไข + Reset + บันทึก ✍️
📝

8 Step เดินเครื่อง

1
Safety: Rope ปล่อย · ฝาปิด · PPE
2
Mode: หน้างาน + HMI = Auto
3
Interlock: เช็คเขียวจากตัวต้น
4
Config: Chip = 100% + Force/Speed
5
Manual test: B11→B12→B13
6
Auto-Start: Confirm 5 วิ → รอ 10 วิ
7
Monitor: HMI · Andon · Dump เขียว
8
Shutdown: หยุดปกติ + บันทึก
